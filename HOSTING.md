# Hosting Recommendation

Best default: GitHub Pages with a custom domain such as `mosaic-robotics.org` or `mosaicroboticslab.org`, then ask the university to redirect the official university URL to that domain.

Why GitHub Pages is a good fit:

- Free and reliable for static academic lab websites.
- Easy version control and student-friendly maintenance.
- Supports custom domains and HTTPS.
- Works with plain HTML, CSS, and JavaScript.
- No server upkeep, database, or build system required for this template.

Good alternatives:

- Cloudflare Pages: excellent performance, generous free tier, very good DNS integration, and simple GitHub deploys.
- Netlify: very friendly deploy flow, forms can be useful for recruiting interest forms, but check long-term account ownership.

Suggested setup:

1. Buy or use a lab-owned domain, not a personal domain.
2. Put this folder in a GitHub repository.
3. Enable GitHub Pages from the repository settings.
4. Configure the custom domain and HTTPS.
5. Ask the university to redirect the official faculty/lab URL to the custom domain.
6. Use Google Forms, Airtable, Qualtrics, or university forms for student/postdoc interest forms rather than collecting form submissions on the static site.

If the university allows only one official faculty profile page, keep that page as the institutional source of truth and link prominently to the lab site.
